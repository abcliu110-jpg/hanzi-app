# 文学常识功能：需求（已确认）

2026-10-31 产品负责人逐项确认。本文件只描述需求，不含实现。

## 1. 位置
- 独立的「文学」页（不放进字义页卡片，不进动画）。

## 2. 年级
- 每条内容标年级：1–2 / 3–4 / 5–6 三档。
- 页面可按年级筛选。

## 3. 数量
- 每字 3–5 条（不按档平均分配，每条各自标年级）。

## 4. 内容类型
- 第一期：古诗名句、成语（含成语故事）、汉字趣闻、课本链接（部编版课文/必背古诗）。
- 第二期：文言用法（虚词；之前动画删掉的文言义项可在此回归）、书法与字体、字谜/对联、名著与人物。

## 5. 配音
- 需要朗读配音，继续使用 edge-tts（App 自用，不商用）。
- 配音后跑多音字检查（tools/anim/polycheck.py 思路）。
- 古诗读音以课本为准（如“斜”等古音读法）。

## 6. 互动小测
- 第一期不做；第二期再加（填诗句、成语配对）。

## 7. 每条内容需记录的信息
字、类型、正文、拼音（含多音字）、白话解释、对应义项、出处（作品/作者/朝代）、年级、核对来源、审核状态（草稿 / 已核对 / 已确认）、是否已配音。

## 8. 选材原则
- 出处可核对；不用网传伪名言；来历有争议的沿用“来历还没有定论”。
- 句中该字的意思与动画义项对应，不对应时明确注明（如“这里的‘之’是‘他’”）。
- 优先课内古诗、常见成语；现代作品只引短句；内容适合儿童。
- 虚词（了、们、么等）难找好名句时，改用汉字趣闻。

## 9. 制作流程
草拟 → 对照权威来源（课本、《汉语大词典》、古籍原文）核对 → 产品负责人审核 → 配音与多音字检查 → 上线。

## 10. 风险
诗句/作者错误、伪名言、古音读法与课本不一致、虚词缺好素材、信息过载、edge-tts 读古诗韵律与多音字不准。
