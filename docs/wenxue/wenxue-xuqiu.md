# 文学常识功能：需求（已确认）

2026-10-31 产品负责人逐项确认。本文件只描述需求，不含实现。

## 1. 位置
- 独立的「文学」页（不放进字义页卡片，不进动画）。

## 2. 年级
- 每条内容标年级：1–2 / 3–4 / 5–6 三档。
- 页面可按年级筛选。

## 3. 数量
- 每字 3–5 条（不按档平均分配，每条各自标年级）。

## 4. 内容类型
- 第一期：古诗名句、成语（含成语故事）、汉字趣闻、课本链接（部编版课文/必背古诗）。
- 第二期：文言用法（虚词；之前动画删掉的文言义项可在此回归）、书法与字体、字谜/对联、名著与人物。

## 5. 配音
- 需要朗读配音，继续使用 edge-tts（App 自用，不商用）。
- 配音后跑多音字检查（tools/anim/polycheck.py 思路）。
- 古诗读音以课本为准（如“斜”等古音读法）。

## 6. 互动小测
- 第一期不做；第二期再加（填诗句、成语配对）。

## 7. 每条内容需记录的信息
字、类型、正文、拼音（含多音字）、白话解释、对应义项、出处（作品/作者/朝代）、年级、核对来源、审核状态（草稿 / 已核对 / 已确认）、是否已配音。

## 8. 选材原则
- 出处可核对；不用网传伪名言；来历有争议的沿用“来历还没有定论”。
- 句中该字的意思与动画义项对应，不对应时明确注明（如“这里的‘之’是‘他’”）。
- 优先课内古诗、常见成语；现代作品只引短句；内容适合儿童。
- 虚词（了、们、么等）难找好名句时，改用汉字趣闻。

## 9. 制作流程
草拟 → 对照权威来源（课本、《汉语大词典》、古籍原文）核对 → 产品负责人审核 → 配音与多音字检查 → 上线。

## 10. 风险
诗句/作者错误、伪名言、古音读法与课本不一致、虚词缺好素材、信息过载、edge-tts 读古诗韵律与多音字不准。

## 11. 背景与目标

## 12. 用户与使用场景
- 孩子（小学 1–6 年级）：自己翻看、点朗读听。
- 家长：按年级挑适合的内容陪读；审核内容（草稿 → 已核对 → 已确认）。

## 14. 功能需求
- F1 独立页面 `wenxue.html`，有返回按钮；首页（index.html、app-shell.html）和字义扩展图（有内容的字）都有入口。
- F2 字列表：列出已有内容的字；选中一个字显示它的全部条目；支持 `?zi=字` 直接打开。
- F3 年级筛选：全部 / 1–2 / 3–4 / 5–6；记住上次选择；某字在当前年级没有内容时给出提示，并可一键切到“全部”。
- F4 类型筛选（第一期 4 类）：古诗名句、成语、汉字趣闻、课本链接。
- F5 条目卡片显示 §7 字段：类型、年级、正文（楷体）、拼音、白话解释、对应义项说明、出处、课本链接、成语故事（可展开）、审核状态。
- F6 朗读：每条有配音时显示“朗读”按钮，播放 / 停止；同一时间只播一条。
- F7 离线：页面和数据随 service worker 预缓存；朗读音频听过一次后缓存。
- F8 file:// 直接打开也能显示内容（与其他页面一致的离线兜底）。

## 15. 验收标准
- A1 首批 100 字中已完成的字，每字 3–5 条；每条都有：字、类型、正文、拼音、白话解释、对应义项、出处、年级、核对来源、审核状态、是否已配音。
- A2 古诗名句、成语出处真实可查（作品 / 作者 / 朝代）；不出现网传伪名言；不确定的课本册次标“待核对”。
- A3 年级筛选后只显示该档条目；刷新后保持；类型筛选同理。
- A4 每条配音存在且可播放；配音后跑多音字检查，读错的已修复或在交接文档登记。
- A5 古诗中的多音字 / 古音按课本读（如“一行白鹭”的 háng、“风吹草低见牛羊”的 xiàn）。
- A6 新条目审核状态一律为“草稿”，页面上有明显标记；只有产品负责人能改成“已确认”。
- A7 `npx playwright test` 全部通过（含新增文学页测试和全站冒烟测试），GitHub CI 通过。
- A8 sw.js 缓存版本升级，离线可打开文学页。
